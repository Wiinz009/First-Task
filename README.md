##  ความประทับใจ 1 เรื่อง
เรื่องที่ผมประทับใจคือการได้เรียนรู้สิ่งใหม่ๆ และสามารถแก้ปัญหาด้วยตัวเอง
เพราะเมื่อทำสำเร็จแล้ว ผมรู้สึกภูมิใจและได้เรียนรู้จากประสบการณ์นั้น
